# How to Add a New Locale

The platform uses `next-intl` for internationalization. Currently, English (`en`) is the default locale.

## Adding a New Locale

1. **Add locale to configuration**:
   Edit `i18n.ts` and add your locale to the `locales` array:
   ```typescript
   export const locales = ['en', 'es', 'fr'] as const;
   ```

2. **Create translation file**:
   Create `messages/[locale].json` (e.g., `messages/es.json`) with translations:
   ```json
   {
     "common": {
       "welcome": "Bienvenido",
       "loading": "Cargando...",
       "error": "Error",
       "success": "Éxito"
     },
     "voucher": {
       "share": "Compartir Cupón",
       "redeem": "Canjear",
       "expired": "Expirado"
     }
   }
   ```

3. **Update middleware** (if needed):
   The middleware can detect locale from headers or URL segments. Update `middleware.ts` if you want locale-based routing.

4. **Use translations in components**:
   ```typescript
   import { useTranslations } from 'next-intl';
   
   function MyComponent() {
     const t = useTranslations('common');
     return <h1>{t('welcome')}</h1>;
   }
   ```

## Locale Detection

The platform can detect locale from:
- URL path prefix (e.g., `/es/v/[id]`)
- Accept-Language header
- User preference (stored in session)

## Currency Formatting

Currency formatting is handled by `formatCurrency` in `lib/utils.ts`, which uses `Intl.NumberFormat`. The currency code comes from the merchant's `defaultCurrency` field.
