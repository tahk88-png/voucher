## 4. BUSINESS RULES KONTROLL

### ✅ Credit süsteem

**Kontrollitud:**

- ✅ Credit algab LOCKED — `app/api/redemptions/route.ts` loob credit'i `status: 'locked'`
- ✅ Credit unlock'itakse pärast redemption confirm — `lib/credits.ts` `unlockCreditForRedemption()`
- ✅ Credit aegub — `expiresAt` väli on olemas (60 päeva default)
- ✅ Credit on merchant-põhine — `merchantId` on kohustuslik
- ✅ Credit ≠ raha — dokumenteeritud, merchant-põhine

**Kood:**

```typescript
// Redemption loob locked credit
await prisma.creditLedger.create({
  data: {
    status: 'locked',
    source: 'referral_redemption',
    // ...
  },
});

// Confirmation unlock'ib
await unlockCreditForRedemption(redemptionId, merchantId);
```

### ✅ Self-referral keelatud

**Kontrollitud:**

- ✅ Server-side kontroll — `app/api/redemptions/route.ts` kontrollib `isSelfReferral()`
- ✅ Funktsioon olemas — `lib/fraud.ts` `isSelfReferral()`
- ✅ Testid olemas — `lib/__tests__/api/redemptions.test.ts` testib self-referral'i

**Kood:**

```typescript
if (data.referralId && session?.user?.id) {
  const isSelf = await isSelfReferral(data.referralId, session.user.id);
  if (isSelf) {
    return NextResponse.json({ error: 'Cannot redeem your own referral' }, { status: 400 });
  }
}
```
