## 2. Outreach Script

### 2a. Opening (DM / WhatsApp / SMS)

> I’m testing a new way to turn your regular customers into your best salespeople, without ads.  
> Can I show you in 10 minutes?

*If they say yes:*  
> When’s a good 10‑minute slot this week? I can call or stop by.

*If they ask “what is it?”:*  
> Your customers get a simple voucher to share. When someone uses it, you give the sharer a bit of store credit. You control the offer and the credit. I’ll set it up with you.

---

### 2b. Phone / in‑person (10‑minute show)

**Minute 0–1 — Hook**  
> You know your best new customers usually come from people who already like you. We’re testing a simple system: your regulars share a voucher, their friend uses it, you decide how much credit the sharer gets. No ads, you stay in control.

**Minute 2–4 — What they get**  
> You get one main voucher — e.g. “15% off first visit” — and one weekly drop: a limited batch, e.g. 30 vouchers for 48 hours. When a friend redeems, your staff confirms in one tap. The referrer gets credit you set — e.g. €5 — to spend with you.

**Minute 5–7 — Why pilot**  
> I’m running this with 10 local businesses to see what works. For the pilot it’s free, I do the setup with you, and you get your own branded voucher. In return I’d want a short feedback call and, if it works, your okay to use the results.

**Minute 8–10 — Close**  
> No contract. If it doesn’t fit, we stop. Want to try it for a few weeks?

---

### 2c. Do NOT say

- “startup”
- “beta”
- “platform”
- “app”

Use: “we’re testing,” “system,” “voucher,” “credit,” “weekly drop.”

---

### 2d. Objection short replies

| Objection | Reply |
| --- | --- |
| “I don’t have time.” | “Setup is one short session. After that it runs itself. 10 minutes to see it?” |
| “Will it cost me?” | “Pilot is free. If we continue after, it would be a small monthly fee and a small amount per referral. We can talk then.” |
| “My customers won’t share.” | “That’s what we’re testing. If almost no one shares, we’ll change the offer or drop it. No risk for you.” |
| “I already have loyalty / discounts.” | “This is different: they only get credit when they bring a new person who actually shows up. It rewards bringing new customers.” |

## 6. Transition to Paid (script, end of pilot)

Use only after a **GO** and when the merchant has seen some results.

> This has been free while we tested.  
> If we keep this running, it will be a small monthly fee plus a small cost per successful referral.  
> We can talk numbers when you’re ready — no pressure.

**Do NOT push pricing. Gauge reaction.**

- If positive: *“I’ll send you the options in a couple of days.”*
- If hesitant: *“No rush. We can run another week or two as is and then decide.”*
- If no: *“Understood. We’ll turn it off when you prefer. Thanks for trying it.”*

### Week 1 — List + outreach

| Day | Task |
| --- | --- |
| 1–2 | Run checklist on 15–20; mark IN/OUT. Pick first 5–7 to contact. |
| 3–5 | DM/call using Section 2. Book 10‑min shows. In‑person best where possible. |
| 6–7 | Do 10‑min shows. Close: “Want to try for a few weeks?” Aim: 3–5 said yes. |

*If too few yes: add 5 more from list, repeat. Don’t change script yet.*

---

### Week 2 — Setup + go‑live

| Day | Task |
| --- | --- |
| 1–3 | Setup sessions (Section 3) with each yes. One session per merchant. |
| 4–5 | All 10 not reached? — outreach to more from list until you have 10. |
| 6–7 | Every merchant: 1 voucher live, 1 weekly drop on, staff shown redeem. Log go‑live dates. |

**Rule:** 7 days with zero referrals → tweak offer/credit/drop for that merchant first; don’t change product.

---

### Week 3–4 — Run + 7–10 day feedback

| When | Task |
| --- | --- |
| Each merchant, 7–10 days after go‑live | 15‑min feedback call (Section 4). Write exact phrases. |
| Weekly | Fill tracker: vouchers shared, referrals, redemptions, credits earned, credits used. |
| If a merchant has 0 in 7 days | Propose one change: e.g. “Try €7 credit” or “30 vouchers for 72h” — one variable at a time. |

| # | Task |

## 8. After Pilot — What to Do Next

### If GO

| # | Task |
| --- | --- |
| 1 | Transition: use Section 6 script. Don’t push. Gauge. |
| 2 | Testimonials: get 3–5 from “Testimonial possible? Yes”. One sentence + name + business OK. |
| 3 | Put quotes in deck / web. Use only with permission. |
| 4 | Pricing: decide monthly + per‑referral; send “options” only to those who reacted positively. |
| 5 | Next 10: same playbook, same ICP. Optionally relax one variable (e.g. 2nd category) to learn. |

### If NO‑GO

| # | Task |
| --- | --- |
| 1 | Messaging: Rewrite hook, “what they get”, objection replies. Test on 2–3 fresh prospects. |
| 2 | Incentives: If “customers didn’t share” dominates — try higher credit or stronger voucher. If “redemptions low” — simplify redemption or offer. |
| 3 | Product: Only if messages + incentives clearly not the cause. One change, then re‑pilot. |

### Regardless

| # | Task |
| --- | --- |
| 1 | Save: all feedback notes, objection phrases, “what felt confusing”. |
| 2 | One‑pager: “What we learned” — 5–7 bullets. Update before next pilot or sales. |

## Pilot Rules (reminder)

| Rule | Detail |
| --- | --- |
| Duration | 14 days minimum, 30 days ideal. At least 1 weekly drop. |
| If nothing in 7 days | Adjust the offer (voucher, credit, drop), not the product. |
| What you get | Usage permission, feedback calls, testimonial if results are positive. |
| What they get | Free pilot, white‑glove setup, branded voucher, weekly drop, direct influence on feedback. |
| No | Contracts, long‑term promises, invented metrics. |
